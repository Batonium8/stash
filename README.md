
# stash

**stash** — это минималистичный командный интерпретатор (shell) для Linux, написанный на C11. 

Я разработал этот проект с нуля чтобы на практике разобраться в системном программировании. Главной целью было понять, как именно устроены процессы и управление потоками ввода-вывода «под капотом» стандартных Linux-терминалов.

Проект решает задачу запуска команд и маршрутизации процессов. Он демонстрирует работу с системными вызовами напрямую, без использования сторонних библиотек для парсинга.

### Основные особенности

* **Параллельные конвейеры:** честная реализация пайпов (`|`), где каждая команда запускается в отдельном дочернем процессе и выполняется параллельно.
* **Перенаправление потоков:** корректная обработка ввода и вывода (`<`, `>`, `>>`) без дедлоков и зависаний за счет аккуратного управления файловыми дескрипторами.
* **Безопасность работы с памятью:** динамически выделяемые токены и AST-структуры рекурсивно очищаются после каждого цикла выполнения команды, что предотвращает утечки (код проверялся через Valgrind).
* **Встроенные команды:** поддержка `cd` и `exit`, которые обрабатываются непосредственно на уровне родительского процесса.

### Установка

Для сборки проекта понадобятся компилятор `gcc` или `clang`, утилита `make` и операционная система на базе Linux.

1. Склонируйте репозиторий:

```bash
git clone https://github.com/batonium8/stash.git
cd stash
```


2. Соберите проект с помощью Makefile:

```bash
make
```

---

### Использование

Для запуска оболочки выполните скомпилированный бинарный файл:

```bash
./stash
```

**Примеры команд:**

```bash
# Выполнение системных утилит с аргументами
path/to/directory $> ls -la /var/log

# Перенаправление вывода в файл и чтение из файла
path/to/directory $> echo "System initialized" > boot.log
path/to/directory $> sort < input.txt >> sorted.txt

# Конвейеры произвольной длины
path/to/directory $> cat /etc/passwd | grep "/bin/bash" | cut -d: -f1

# Навигация и выход
path/to/directory $> cd /tmp
path/to/directory $> exit
```
